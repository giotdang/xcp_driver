# Test Strategy

Sau khi update tính năng mới hoặc fix bug một tính năng, bạn cần chạy Unit Test và Integration Test liên quan tới tính năng đó để kiểm tra. 

Còn việc chạy toàn bộ các test sẽ chỉ làm khi người dùng đưa ra yêu cầu cụ thể.
